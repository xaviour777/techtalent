# TalentPlus — Immersive Website

Immersive, Foundera-style tour website for Gushcloud Talent Plus (talentplus.me), built for Shahid's client.

- 7-stop tour: Arrival, Creator Lounge, Campaign Floor, Beauty & Play Room, Strategy Room, Screening Room, Dubai Rooftop
- Static site: open `index.html` or deploy as-is on Vercel / Cloudflare Pages / GitHub Pages.
- Images are served from Vercel's file CDN.
